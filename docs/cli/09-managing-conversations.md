# 管理会话

恢复先前的开发线程、将活动历史限定在本地 workspace（工作区）作用域，并通过分叉会话来探索不同的架构设计。

## Workspace 作用域隔离

为保持上下文的纯净度，Antigravity CLI 会将对话历史直接限定在当前工作目录的作用域内。当您在某个特定目录启动 `agy` 时，agent 仅会显示并恢复与该特定本地代码仓库或子目录关联的会话。

这能有效防止上下文污染，确保 agent 的语义记忆和 token 额度始终专注于相关的代码库。

## 恢复会话

您可以随时返回到先前的会话，以继续方案实现、优化解决方案或从中断的会话中恢复。

Antigravity CLI 既支持交互式的 **Session Picker** TUI 浮层面板，也支持直接使用命令行 flag（`agy -c` / `agy --continue`）根据您当前的活动 workspace 立即恢复会话线程。

有关交互式选择器、键盘快捷键以及目录作用域会话缓存工作机制的完整说明，请参阅专用的 **[Resume 命令指南](/docs/cli/commands/resume)**。

## 使用 `/fork` 进行分支实验

在开发复杂特性时，您可能希望探索多种设计方案，同时又不丢失现有进度。`/fork` 命令可实现安全且并行的探索性实验。

```
/fork
```

_（别名：`/branch`）_

`/fork` 命令会将截至当前 turn（轮次）的完整会话历史克隆到一个全新的独立会话中。

### Fork 工作流

1. 在 prompt 面板中输入 `/fork` 并按 `Enter`。
2. CLI 会分配一个新的唯一会话 ID，并复制现有的 workspace 状态与 agent 线程。
3. 当前活动的终端会立即切换到新分支。
4. 如果实验未达预期，运行 `/resume` 即可恢复原始、稳定的对话分支。

> [!NOTE]
> **文件系统分支提示**：分叉操作克隆的是*对话线程*，而非您本地的 git 检出代码。为了在并行分叉期间完全隔离文件，在测试不同方案前请使用 git 分支或 stash 暂存本地更改。
