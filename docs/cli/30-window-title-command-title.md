# 窗口标题命令 (/title)

交互式配置动态终端窗口标题。

## 概述

`/title` 命令允许你开启或关闭终端窗口标题功能，或者显式设置其状态。启用后，终端标题栏将动态更新以显示当前活跃的模型、workspace（工作区）以及 agent（智能体/代理）状态。

有关如何编写自定义脚本以格式化窗口标题的详细信息，请参阅概念文档 **[终端标题自定义指南](/docs/cli/title)**。

## 交互式切换

你可以通过运行 `/title` 命令来控制窗口标题功能。

若要开启或关闭该功能：

```
/title
```

若要显式启用：

```
/title on
```

若要显式禁用：

```
/title off
```
